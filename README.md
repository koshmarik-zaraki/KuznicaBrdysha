## Как

1. Переходим по ссылочке и забираем KuznicaBrdysha-Setup-1.1.2.exe (установщик). ZIP — если не хочешь установку.
2. Установил лаунчер, открыл.
3. Настройки → указал папку Dota (если не поставилась сама)
4. Слева натыкал моды.
5. Внизу **Установить**.
6. Потом **Запустить Dota 2**. Не из Steam напрямую — из лаунчера.

Патч доты снёс моды? Те же две основные кнопки в лаунчере: **Удалить** и **Установить**.

Сет не поставился? ИДИ НАХУЙ (удалить и установить)

Пресеты можно сохранить и скинуть кенту `.json` файлом (вкладка Профиль).

Дота не запускается? Steam → Dota 2 → проверить файлы. Потом снова **Установить** в лаунчере.

## Важные штуки

1. Для перекраски и своих иконок необходимо докачать Workshop Tools DLC (Steam → Dota → Свойства → Доп. контент → Workshop Tools DLC ~5гб)
2. Лаунчер сам прописывает параметры запуска (если запускать через него). Если вдруг не справился: Steam → Dota → Свойства → Общие → в параметрах запуска `-language russian`
3. В верхнем правом углу есть кнопка «Обновить каталог»
4. Пока что на ум ниче не приходит, вроде в остальном все ez и в дальнейшем работать буду по фидбеку. Всем спасибо
