# Кузница Брдыща v1.0.0

Моды в доту без ручной возни. Отметил → поставил → запустил.

**Банят? НЕТ (случаи не зарегистрированы)!**

Скачать: [Releases](https://github.com/koshmarik-zaraki/KuznicaBrdysha/releases/latest) — файл **KuznicaBrdysha-Setup-1.0.0.exe**.

Поддержка: [t.me/koshmarik_bazza](https://t.me/koshmarik_bazza)

## Как

1. Установил лаунчер, открыл.
2. Настройки → указал папку Dota (Steam → Dota 2 → Свойства → файлы → Обзор).
3. Слева натыкал моды.
4. Внизу **Установить**.
5. Потом **Запустить Dota 2**. Не из Steam напрямую — из лаунчера.

Патч доты снёс моды? Снова **Удалить** и **Установить**.

Пресеты можно сохранить и скинуть кенту `.json` файлом (вкладка Профиль).

Дота не запускается? Steam → Dota 2 → проверить файлы. Потом снова **Установить** в лаунчере.

## Важные штуки

1. Для перекраски набора/шмотки необходимо докачать Workshop Tools DLC (Steam → Dota → Свойства → Доп. контент → Workshop Tools DLC, ~5 ГБ).
2. Лаунчер сам прописывает параметры запуска в файлы игры (если запускать через него), но если вдруг не справился: Steam → Dota → Свойства → Общие → в параметрах запуска `-language russian`.
3. Пока что на ум ниче не приходит, вроде в остальном все ez.
